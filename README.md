# OT-3D-ui-beta

Modern 3D Spatial UI & Utility Engine for Roblox Client / Executor.

## ✨ Features
- **3D Spatial Interface:** Interactive floating 3D part anchored in front of the camera with drag-to-move and resize handles.
- **Player Controls:** WalkSpeed, JumpPower, Bunny Hop (Bhop with physics momentum and speed gauge HUD), Universal Fly (PC & Mobile), Noclip, and Infinite Jump.
- **Visuals & Combat:** Post-render smooth Camlock system, Player ESP (Chams Highlight), and Fullbright mode.
- **Character Look & Cosmetics (Wardrobe UI):**
  - Dedicated dressing-room camera view (facing front of character, orbit 360° inspection).
  - Floating 3D window on the side with draggable Grab Bar.
  - Rainbow Chroma Skin, Ghost Mode, Forcefield Shield, Neon Glow, Sparkles/Fire Aura, Accessory Toggles, and Character Pose Freeze.
- **Settings & Utility:** 20-minute Anti-AFK guard and Server Rejoin.
- **Automated Backup System:** Retains snapshots of previous updates in the `backups/` directory.
